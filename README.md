# 不期而宿 —— 基于冲突规避矩阵的宿舍智能分配系统

## 项目简介

本项目面向高校新生宿舍分配场景，针对传统随机分配导致室友生活习惯冲突频发的问题，设计并实现了一套基于**冲突规避矩阵**的宿舍智能分配系统。

核心思想：**不追求"找到最合拍的室友"，而是"强力排除最不能忍受的冲突"。**

学生通过填写11维度偏好问卷，系统将"完全不能忍受"的属性设为硬约束，将宿舍分配问题转化为约束满足问题（CSP），采用回溯搜索算法求解，确保分配结果零硬冲突。

## 系统功能

### 学生端
- 身份证号登录（密码为身份证后六位）
- 填写偏好问卷（11题，涵盖作息、吸烟、打鼾、卫生、游戏开麦、忍耐度等维度）
- 查看宿舍分配结果（楼栋、房间号、床位号、室友信息）

### 管理员端
- 学生信息管理（新增、编辑、删除、手动分配宿舍）
- 宿舍资源管理（楼栋、房间、容量维护）
- 系统开关控制（系统总开关、问卷填写开关、分配算法开关）
- 一键执行智能分配
- 查看分配结果
- 仪表盘数据统计

## 核心算法

### 冲突规避矩阵
将学生之间的"不宜同住关系"显式建模为冲突矩阵。五类硬冲突规则：
- 吸烟冲突：A完全不能忍受抽烟 + B经常抽烟
- 作息冲突：A完全不能忍受晚睡 + B凌晨后睡觉
- 打鼾冲突：A完全不能忍受打呼噜 + B经常打呼噜
- 开麦冲突：A完全不能忍受开麦 + B经常开麦
- 卫生冲突：A完全不能忍受卫生差 + B卫生习惯随意

### 回溯搜索求解
将宿舍分配问题形式化为约束满足问题（CSP）：
- 变量：每名待分配学生
- 值域：可用宿舍床位
- 约束：性别一致、专业相同、容量≤6、冲突对不能同宿

求解时引入两个优化策略：
- **前向检查**：每次分配后提前排除无效分支
- **MRV启发式**：优先安排可选择性最少的学生
